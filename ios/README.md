# FILTER CITY HRMS iOS Store Build

Prepared bundle identifier: `com.filtercity.hrms`
Version: `1.0.0` (build 1)

Build with Xcode 26 or later using the iOS 26 SDK or later. Generate the Xcode project from `project.yml` with XcodeGen, select the publishing Apple Developer team, test on a physical iPhone, then create and validate an App Store archive.

Before submission, add the final approved app icon, test Admin and Employee login, attendance location, task photo upload, English/Arabic UI, and the Privacy Policy and Support links. Complete App Privacy and age-rating information in App Store Connect.
